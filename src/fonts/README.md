# Self-hosted fonts (OFL)

Variable TTFs vendored so `next build` does **not** fetch Google Fonts (fixes Docker/EasyPanel offline builds).

| File | Family | Source |
|------|--------|--------|
| `Syne-Variable.ttf` | Syne | [google/fonts ofl/syne](https://github.com/google/fonts/tree/main/ofl/syne) |
| `Figtree-Variable.ttf` | Figtree | [google/fonts ofl/figtree](https://github.com/google/fonts/tree/main/ofl/figtree) |
| `Figtree-Italic-Variable.ttf` | Figtree Italic | same |
